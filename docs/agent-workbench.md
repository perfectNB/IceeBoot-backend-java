# 智能体运行工作台

## 功能入口

- 智能体配置底部「技能与环境预检」检查最近保存的草稿。配置绑定错误会阻断；启用沙箱时会创建临时环境，检查工作目录、Python 清单中的已安装包及静态可识别的导入模块，最后释放环境。不调用模型，不执行技能脚本，不安装依赖。动态导入、npm 包及依赖版本约束需另外核对，界面会明确提示。
- 对话展示环境准备、模型调用、工具执行累计耗时、首个模型内容等待和输入/输出 Token。子智能体也计入模型与工具总量；并行阶段不应与总时间相加。环境准备包含装配、沙箱启动和同步等子阶段。只有供应商完整返回 usage 才显示完整用量，缺失时显示未知；历史旧记录不推算耗时。此处不是金额计费。
- 对话输入框支持附件；每轮最多 5 个、合计 20MiB，单文件 20MiB，每会话总文件容量 100MiB。当前会话固定的发布版本必须启用沙箱。未发送附件可移除，刷新后会恢复。需要再次处理历史文件时点击「加入本轮」。
- 模型使用 `deliver_artifact` 交付当前工作目录 `/home/user/workspace` 下的文件。文件必须通过交付工具保存，单轮最多 20 个；不能仅在回答中写本地路径。文件保存后可下载，即使本轮沙箱关闭也不受影响。
- 失败、超时、取消或中断后可「准备重试」：创建独立会话，固定原发布版本，复制本轮输入附件，并在 100000 字符限制内带入最近可见历史（超限时仅保留本次问题）。输入可编辑，确认发送才重新执行。失败的部分答案和待执行工具状态不复制，避免自动重放外部操作。这不是任意步骤的无损检查点续跑。
- 「版本」可比较两个不可变快照，覆盖模型、提示词、能力和子智能体。密钥、请求头、环境值只显示变更提示。回滚复制所选快照创建新版本并原子切换当前版本，保留全部历史；旧会话仍使用原版本，草稿保持不变。

## 存储和权限

文件元数据存 `t_agent_file`，内容以 256KiB 分块存 `t_agent_file_chunk`，输入/输出归属存 `t_agent_run_file`。文件不生成公开访问 URL，上传、列表、绑定、删除、下载都校验 `agentId + 当前登录 userId + sessionId`。文件名不允许路径或控制字符。下载强制附件、`no-store`、`nosniff`；生成文件通过 envd 二进制接口读取，限制实际接收字节数，避免 Shell 的 512KiB 输出限制。

启动时自动执行新增迁移 V012（文件表）和 V013（接口权限）。新增八个接口均使用动态权限并只授权有效超级管理员，按钮按权限显示；普通角色不自动扩权。重启后端后重新加载权限，才能使用新入口。数据库部署需确保对这三张表的备份和容量规划。

实时和历史过程使用同一 `AgentProgress` 契约；新增可空 `durationMs/inputTokens/outputTokens/usageKnown`，兼容旧事件。正文增量不重复持久化，计时和最终 usage 事件持久化，模型调用按调用 ID 入账一次。

## 验证

两端 `scripts/verify.sh` 包含实际数据库存取、会话隔离、20MiB 分块、归档同步、SDK 二进制读取、回滚事务、重试版本固定、权限迁移、事件流和前端交互测试。云模板连通性另行验证，不混入自动化测试，也不在测试中调用付费模型。
