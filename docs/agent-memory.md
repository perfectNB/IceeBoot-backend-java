# 结构化长期记忆

在「智能体管理 → 长期记忆」中选择智能体和记忆范围，填写画像提示词，添加字段并启用策略。智能体专属策略与公共经验策略随智能体发布，在新会话中使用。已有会话沿用创建时的发布版本。平台通用策略单独配置，从下一轮生效。三个范围默认关闭。

| 范围 | 归属 | 使用方式 |
| --- | --- | --- |
| 我的专属画像 | 智能体 + 当前用户 | 同一个用户与同一个智能体的新会话可以继续使用 |
| 我的通用画像 | 当前用户 | 用户为每个智能体分别勾选可读取、可提议更新的字段 |
| 智能体公共经验 | 智能体 | 授权审核员确认后，才对该智能体的其他用户生效 |

**对话读取。** 服务端从登录身份和会话确定归属。每轮读取一次，过滤共享字段和忘记标记，并将参考数据放在发往模型的消息副本中，最多 6000 个字符。专属、通用、公共按此顺序占用预算。画像本身不会作为一条新消息写入聊天记录。普通工具调用复用本轮快照，子智能体独立运行。

**后台更新。** 根对话成功结束和提取任务入队使用同一个事务。Quartz 在后台认领任务，使用该会话已发布版本的模型，一次调用处理有写入权限的范围，单独记账。只将本轮用户原话视作证据。定时任务、自动拼接的历史重试输入和子智能体任务不会生成提取任务。启用后会增加模型用量。后台完成前，新会话读取最近一次已经保存的画像。

**确认与忘记。** 候选必须符合字段定义并提供能在用户原话中找到的引用。共享经验始终需要审核。适用范围、用户授权、策略版本、画像版本和忘记标记在写入前再次核对。已变化的候选不会覆盖新值。手动忘记后，该字段从当前画像移除并停止自动提取，手动填写可以恢复。聊天原文及加密审计记录有各自的存储周期。语义是否理解正确仍取决于模型与提示词，重要字段可开启人工确认。

**存储与权限。** V016 创建策略、画像、共享授权、更新任务和变更记录五张表，V017 安装菜单、接口及超级管理员的默认关联。画像内容、原话快照、候选和证据使用既有应用密钥加密。授权按字段存于数据库，每轮从库读取。普通角色从权限管理分配所需菜单和接口。个人接口从令牌取用户身份。公共经验编辑与审核、平台提示词配置均有独立权限。
