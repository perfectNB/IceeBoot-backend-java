# 结构化长期记忆

在「智能体 → 配置 → 长期记忆」中管理当前智能体的画像策略、记忆内容和共享授权，无需再次选择智能体。通用画像不放在智能体配置中，通过独立的「通用画像」菜单统一管理所有用户的画像及提取规则；每个用户的内容仍按用户 ID 隔离。填写画像提示词，添加字段并启用策略。智能体专属策略与公共经验策略随智能体发布，在新会话中使用。已有会话沿用创建时的发布版本。平台通用策略单独配置，从下一轮生效。三个范围默认关闭。

| 范围 | 归属 | 使用方式 |
| --- | --- | --- |
| 我的专属画像 | 智能体 + 当前用户 | 同一个用户与同一个智能体的新会话可以继续使用 |
| 通用画像 | 每个用户独立归属，统一配置提取策略 | 管理员按用户查看、编辑和审核；智能体读取仍受用户字段授权约束 |
| 智能体公共经验 | 智能体 | 授权审核员确认后，才对该智能体的其他用户生效 |

**对话读取。** 服务端从登录身份和会话确定归属。每轮读取一次，过滤共享字段和忘记标记，并将参考数据放在发往模型的消息副本中，最多 6000 个字符。专属、通用、公共按此顺序占用预算。画像本身不会作为一条新消息写入聊天记录。普通工具调用复用本轮快照，子智能体独立运行。

**后台更新。** 根对话成功结束和提取任务入队使用同一个事务。Quartz 在后台认领任务，使用该会话已发布版本的模型，一次调用处理有写入权限的范围，单独记账。只将本轮用户原话视作证据。定时任务、自动拼接的历史重试输入和子智能体任务不会生成提取任务。启用后会增加模型用量。后台完成前，新会话读取最近一次已经保存的画像。

**确认与忘记。** 候选必须符合字段定义并提供能在用户原话中找到的引用。共享经验始终需要审核。适用范围、用户授权、策略版本、画像版本和忘记标记在写入前再次核对。已变化的候选不会覆盖新值。手动忘记后，该字段从当前画像移除并停止自动提取，手动填写可以恢复。聊天原文及加密审计记录有各自的存储周期。语义是否理解正确仍取决于模型与提示词，重要字段可开启人工确认。

**存储与权限。** V016 创建策略、画像、共享授权、更新任务和变更记录五张表，V017 安装菜单、接口及超级管理员的默认关联。画像内容、原话快照、候选和证据使用既有应用密钥加密。授权按字段存于数据库，每轮从库读取。普通角色从权限管理分配所需菜单和接口。个人接口从令牌取用户身份。公共经验编辑与审核、平台提示词配置均有独立权限。

## 配置入口与保存

V018 将智能体专属记忆移入智能体配置；V019 将原菜单恢复并更名为「通用画像」，保留菜单 ID、路由与角色关联。智能体内仅保留专属画像、公共经验和当前用户对该智能体的画像授权。

记忆编辑器固定当前智能体 ID；新智能体需先保存草稿取得 ID。未打开记忆分区时不请求记忆接口。切换设置分区、记忆范围或策略/共享标签时保留待保存的策略和授权。

可在记忆分区单独保存，也可使用弹窗的「保存草稿」「保存并发布」：先逐项保存未保存的记忆策略/共享授权，校验失败时回到对应范围，不继续保存或发布智能体。个人画像的手动编辑/忘记仍通过各自操作立即保存。记忆设置和智能体草稿是独立服务调用，记忆保存成功后若智能体草稿保存失败，应重试草稿保存；不会发布失败的草稿。

## 跨用户管理权限与审计

「通用画像 → 用户画像」分页查询非删除用户，只返回用户 ID、账号、昵称和状态，不批量读取画像内容或完整用户资料。选择用户后才读取该用户的通用画像。统一画像策略单独配置，适用于所有用户，不将不同用户的内容合并。

新增 `/v1/agent-console/memory/users` 管理接口与 `ai:memory:user-*` 六个动态权限，默认只授予有效超级管理员。跨用户管理服务逐项检查对应权限，当前登录身份作为操作人，路径用户 ID 作为画像归属，审计分别记录两者。缺少管理权限、用户不存在或已删除时拒绝访问。原「我的记忆」接口仍只从登录令牌取得归属，不能借此查询其他用户。

菜单和接口变更由 V019 自动升级。重启后端并重新登录后，侧栏显示「通用画像」。
