# ZBoot 代码生成器文档

## 概述

ZBoot 代码生成器是一个基于 Beetl 模板引擎的智能代码生成工具，能够快速生成标准的 Spring Boot 项目代码结构。它遵循 DDD（领域驱动设计）和分层架构原则，自动生成完整的 CRUD 操作代码，包括 Controller、Service、Mapper、Entity、DTO、VO 等各层代码文件。

### 核心特性

- **模板驱动**：基于 Beetl 模板引擎，支持灵活的模板定制
- **分层架构**：严格遵循分层架构设计，生成标准的企业级代码结构
- **智能删除**：支持智能代码删除，根据实体字段数量给出不同提示
- **备份恢复**：删除代码时自动备份，支持一键恢复
- **包结构管理**：自动创建和管理完整的包结构
- **统一规范**：生成的代码遵循统一的命名规范和编码标准

### 核心组件

#### 1. CodeGenerator 主类

<mcfile name="CodeGenerator.java" path="src/main/java/com/iceeboot/generator/CodeGenerator.java"></mcfile> 是代码生成器的核心类，负责：

- **模板引擎初始化**：配置 Beetl 模板引擎
- **代码生成控制**：协调各个生成步骤
- **文件管理**：处理文件的创建、删除、备份
- **用户交互**：提供智能的删除确认机制

#### 2. 模板系统

模板文件位于 <mcfolder name="templates" path="src/main/resources/templates"></mcfolder> 目录下：

| 模板文件 | 生成内容 | 说明 |
|---------|---------|------|
| controller.btl | Controller 层 | RESTful API 控制器 |
| service.btl | Service 接口 | 业务逻辑接口定义 |
| serviceImpl.btl | Service 实现 | 业务逻辑具体实现 |
| mapper.btl | Mapper 接口 | 数据访问层接口 |
| entity.btl | 实体类 | 数据库实体对象 |
| createDto.btl | 创建 DTO | 数据传输对象（创建） |
| updateDto.btl | 更新 DTO | 数据传输对象（更新） |
| vo.btl | 视图对象 | 前端展示对象 |
| query.btl | 查询对象 | 查询条件封装 |
| mapperXml.btl | Mapper XML | MyBatis 映射文件 |

## 模板详解

### 1. Controller 模板

<mcfile name="controller.btl" path="src/main/resources/templates/controller.btl"></mcfile> 生成标准的 RESTful API 控制器：

**特性：**
- 支持 Swagger 文档注解
- 提供完整的 CRUD 操作接口
- 统一的响应格式（R<T>）
- 分页查询支持
- 批量删除功能

**生成的接口：**
- `GET /api/v1/{entity}` - 分页查询
- `POST /api/v1/{entity}` - 创建实体
- `PUT /api/v1/{entity}` - 更新实体
- `GET /api/v1/{entity}/{id}` - 根据ID查询
- `DELETE /api/v1/{entity}` - 批量删除

### 2. Service 模板

<mcfile name="service.btl" path="src/main/resources/templates/service.btl"></mcfile> 生成业务逻辑接口：

**特性：**
- 继承 MyBatis-Plus 的 IService 接口
- 定义标准的业务方法
- 完整的 JavaDoc 注释
- 类型安全的方法签名

### 3. ServiceImpl 模板

<mcfile name="serviceImpl.btl" path="src/main/resources/templates/serviceImpl.btl"></mcfile> 生成业务逻辑实现：

**特性：**
- 继承 MyBatis-Plus 的 ServiceImpl
- 实现分页查询逻辑
- 对象转换（Entity ↔ DTO ↔ VO）
- 异常处理机制
- 日志记录

### 4. Entity 模板

<mcfile name="entity.btl" path="src/main/resources/templates/entity.btl"></mcfile> 生成数据库实体类：

**特性：**
- 继承基础实体类 IceeBootDO
- MyBatis-Plus 注解支持
- Swagger 文档注解
- 标准的表命名规范（t_{entity}）

### 5. DTO 模板

**CreateDTO** 和 **UpdateDTO** 模板生成数据传输对象：

**特性：**
- 参数校验注解（@NotBlank 等）
- Swagger 文档注解
- 分离创建和更新场景
- 类型安全

### 6. VO 模板

<mcfile name="vo.btl" path="src/main/resources/templates/vo.btl"></mcfile> 生成视图对象：

**特性：**
- 包含基础字段（id、创建时间、更新时间）
- JSON 格式化注解
- Swagger 文档注解
- 前端友好的数据结构

### 7. Query 模板

<mcfile name="query.btl" path="src/main/resources/templates/query.btl"></mcfile> 生成查询条件对象：

**特性：**
- 继承基础查询类 BaseQuery
- 支持分页参数
- 时间范围查询
- 灵活的查询条件

### 8. Mapper 模板

<mcfile name="mapper.btl" path="src/main/resources/templates/mapper.btl"></mcfile> 和 <mcfile name="mapperXml.btl" path="src/main/resources/templates/mapperXml.btl"></mcfile> 生成数据访问层：

**特性：**
- 继承 MyBatis-Plus 的 BaseMapper
- 标准的结果映射
- 基础字段定义
- 预留自定义查询方法

@Override
public PageResult<UserVO> getUserPage(UserQuery query) {
    LambdaQueryWrapper<UserDO> wrapper = new LambdaQueryWrapper<>();
    wrapper.like(StringUtils.hasText(query.getUsername()), UserDO::getUsername, query.getUsername())
           .eq(StringUtils.hasText(query.getStatus()), UserDO::getStatus, query.getStatus())
           .ge(query.getStartTime() != null, UserDO::getCreateTime, query.getStartTime())
           .le(query.getEndTime() != null, UserDO::getCreateTime, query.getEndTime())
           .orderByDesc(UserDO::getCreateTime);

    IPage<UserDO> result = this.page(page, wrapper);
    
    List<UserVO> voList = result.getRecords().stream().map(entity -> {
        UserVO vo = new UserVO();
        BeanUtils.copyProperties(entity, vo);
        return vo;
    }).collect(Collectors.toList());
    
    return new PageResult<>(voList, result.getTotal(), (long) query.getPageNum(), (long) query.getPageSize());
}

private void writeFile(String filePath, String content) throws IOException {
    File file = new File(filePath);
    File parentDir = file.getParentFile();
    if (!parentDir.exists()) {
        parentDir.mkdirs();
    }
    
    try (FileWriter writer = new FileWriter(file)) {

    }

// 文件备份
private void backupFile(String filePath) {
    File file = new File(filePath);
    if (file.exists()) {
        try (BufferedReader reader = new BufferedReader(new FileReader(file))) {
            StringBuilder content = new StringBuilder();
            String line;
            while ((line = reader.readLine()) != null) {
                content.append(line).append("\n");
            }
            backupFiles.put(filePath, content.toString());
        } catch (IOException e) {
            System.err.println("备份文件失败: " + filePath + ", " + e.getMessage());
        }
    }
}

### 3. 智能检测

```java
// 统计实体类字段数量
private int countEntityFields(String entityPath) {
    File file = new File(entityPath);
    if (!file.exists()) {
        return 0;
    }
    
    try (BufferedReader reader = new BufferedReader(new FileReader(file))) {
        String line;
        int fieldCount = 0;
        boolean inClassBody = false;
        
        while ((line = reader.readLine()) != null) {
            line = line.trim();
            
            if (line.contains("public class") && line.contains("{")) {
                inClassBody = true;
                continue;
            }
            
            if (inClassBody) {
                Pattern fieldPattern = Pattern.compile("^(private|protected|public)\\s+\\w+.*\\s+\\w+\\s*;");
                Matcher matcher = fieldPattern.matcher(line);
                
                if (matcher.find() && 
                    !line.contains("static") && 
                    !line.contains("final") &&
                    !line.startsWith("//") &&
                    !line.startsWith("*")) {
                    fieldCount++;
                }
            }
        }
        
        return fieldCount;
    } catch (IOException e) {
        System.err.println("读取实体类文件失败: " + e.getMessage());
        return 0;
    }
}
```

## 故障排除

### 常见问题

#### 1. 模板文件找不到

**问题**：`Template not found: xxx.btl`

**解决方案**：
- 检查模板文件是否存在于 `src/main/resources/templates/` 目录
- 确认模板文件名拼写正确
- 检查类路径配置

#### 2. 文件生成失败

**问题**：`IOException: Permission denied`

**解决方案**：
- 检查目标目录写权限
- 确认文件未被其他程序占用
- 检查磁盘空间是否充足

#### 3. 包结构错误

**问题**：生成的文件包路径不正确

**解决方案**：
- 检查 BASE_PACKAGE 配置
- 确认 packageName 参数格式
- 验证目录创建逻辑

#### 4. 模板变量未替换

**问题**：生成的代码中包含 `${variableName}` 原始变量

**解决方案**：
- 检查模板变量名拼写
- 确认变量已正确传递给模板
- 验证 Beetl 语法正确性

### 调试技巧

1. **启用详细日志**：设置日志级别为 DEBUG
2. **单步调试**：使用 IDE 断点调试
3. **模板测试**：单独测试模板渲染
4. **文件检查**：验证生成文件内容
