## 项目概述

### 项目简介

ZBoot 是一个基于 Spring Boot 3.x + AI 大模型 + Vue 3 + TypeScript 的现代化企业级全栈开发脚手架。项目致力于为开发者提供一个开箱即用、功能完备、易于扩展的后端开发基础设施。

### 核心特性

- **🚀 开箱即用**：最小化配置，最大化功能
- **🤖 AI 智能化**：深度集成 AI 大模型和智能体技术
- **🔐 企业级安全**：完善的权限控制和安全防护机制
- **📈 高性能**：基于 Spring WebFlux 的响应式编程
- **🛠️ 代码生成**：智能化代码生成器，提升开发效率
- **📊 监控运维**：完善的系统监控和日志管理

### 技术栈

#### 后端核心
- **Spring Boot 3.5.5** - 企业级应用框架
- **Spring WebFlux** - 响应式编程支持
- **MyBatis-Plus 3.5.9** - 数据持久化框架
- **Sa-Token 1.37.0** - 权限认证框架
- **MySQL 8.0+** - 主数据库
- **Redis Stack 7.0+** - 缓存和向量数据库

#### AI 与智能化
- **Spring AI Alibaba 1.0.0** - 阿里云 AI 服务集成
- **Spring AI 1.0.0** - AI 模型统一接口
- **RAG 检索增强生成** - 知识库检索增强
- **MCP 协议** - AI 模型上下文协议

#### 其他组件
- **Activiti 7.1.0** - 工作流引擎
- **Quartz** - 定时任务调度
- **RabbitMQ** - 消息队列
- **Elasticsearch** - 全文搜索
- **MongoDB** - 文档数据库
- **多云存储** - 阿里云OSS、腾讯云COS、华为云OBS等

### 项目启动

1. **克隆项目**
   ```bash
   git clone https://gitee.com/woshinibaba438cnmlgb/zboot-backend-java.git
   cd zboot-backend-java
   ```

2. **配置数据库**
   ```yaml
   # application-local.yml
   spring:
     datasource:
       url: jdbc:mysql://localhost:3306/zboot?allowPublicKeyRetrieval=true&useUnicode=true&characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=false&serverTimezone=GMT%2B8
       username: your_username
       password: your_password
   ```

3. **配置 Redis**
   ```yaml
   # application-local.yml
   spring:
     data:
       redis:
         host: localhost
         port: 6379
         password: your_password
   ```

4. **启动项目**
   ```bash
   mvn spring-boot:run
   ```

5. **访问接口文档**
   - Knife4j 文档：http://localhost:8080/doc.html

### 模块说明

#### Common 模块
- **annotation**: 自定义注解，如 `@RequirePermission`、`@RateLimit`
- **aspect**: AOP 切面，实现横切关注点
- **constant**: 系统常量和缓存键定义
- **exception**: 全局异常处理和自定义异常
- **service**: 公共服务，如 AI、OSS、短信、邮件等
- **utils**: 工具类，如加密、Redis、Token 等

#### Config 模块
- **ai**: AI 模型配置和 Spring AI 集成
- **cache**: Redis 配置和序列化设置
- **security**: Sa-Token 安全配置和权限实现
- **mybatisplus**: MyBatis-Plus 配置和自动填充

#### Framework 模块
- **controller**: RESTful API 控制器
- **service**: 业务逻辑服务层
- **mapper**: MyBatis 数据访问层
- **entity**: JPA 实体类和数据库映射
- **dto**: 数据传输对象，用于接口参数
- **vo**: 视图对象，用于接口返回
- **query**: 查询条件对象

## 开发规范

### 代码规范

#### 命名规范

1. **类命名**
   - 控制器：`XxxController`
   - 服务接口：`IXxxService`
   - 服务实现：`XxxServiceImpl`
   - 实体类：`XxxDO`
   - DTO：`XxxDTO`
   - VO：`XxxVO`
   - 查询对象：`XxxQuery`

2. **方法命名**
   - 查询：`get`、`find`、`list`、`page`
   - 新增：`create`、`add`、`save`
   - 修改：`update`、`modify`
   - 删除：`delete`、`remove`
   - 判断：`is`、`has`、`can`

3. **包命名**
   - 按功能模块划分：`com.iceeboot.framework.service.system`
   - 按层次划分：`controller`、`service`、`mapper`、`entity`

#### 注解规范

1. **权限控制**
   ```java
   @RequirePermission("system:user:list")
   @GetMapping("/list")
   public Result<PageResult<SysUserVO>> getUserList(SysUserQuery query) {
       // 实现逻辑
   }
   ```

2. **接口限流**
   ```java
   @RateLimit(key = "user:login", time = 60, count = 5)
   @PostMapping("/login")
   public Result<LoginVO> login(@RequestBody LoginDTO loginDTO) {
       // 实现逻辑
   }
   ```

3. **API 文档**
   ```java
   @Operation(summary = "获取用户列表", description = "分页查询系统用户信息")
   @Parameter(name = "query", description = "查询条件")
   @GetMapping("/list")
   public Result<PageResult<SysUserVO>> getUserList(SysUserQuery query) {
       // 实现逻辑
   }
   ```

#### 异常处理规范

1. **业务异常**
   ```java
   if (user == null) {
       throw new ServiceException("用户不存在");
   }
   ```

2. **参数校验**
   ```java
   @NotBlank(message = "用户名不能为空")
   @Length(min = 4, max = 20, message = "用户名长度必须在4-20个字符之间")
   private String username;
   ```

### 数据库规范

#### 表设计规范

1. **表命名**：使用小写字母和下划线，如 `sys_user`、`sys_role`
2. **字段命名**：使用小写字母和下划线，如 `user_id`、`create_time`
3. **主键**：统一使用 `id` 作为主键，类型为 `bigint`
4. **公共字段**：
   ```sql
   CREATE TABLE sys_user (
       id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
       create_time DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
       update_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
       create_by VARCHAR(64) COMMENT '创建人',
       update_by VARCHAR(64) COMMENT '更新人',
       del_flag TINYINT DEFAULT 0 COMMENT '删除标志(0-未删除,1-已删除)'
   ) COMMENT '系统用户表';
   ```

#### 实体类规范

```java
@Data
@TableName("sys_user")
@ApiModel(description = "系统用户实体")
public class UserDO {
    
    @TableId(type = IdType.AUTO)
    @ApiModelProperty("用户ID")
    private Long id;
    
    @ApiModelProperty("用户名")
    private String username;
    
    @TableField(fill = FieldFill.INSERT)
    @ApiModelProperty("创建时间")
    private LocalDateTime createTime;
    
    @TableField(fill = FieldFill.INSERT_UPDATE)
    @ApiModelProperty("更新时间")
    private LocalDateTime updateTime;
    
    @TableField(fill = FieldFill.INSERT)
    @ApiModelProperty("创建人")
    private String createBy;
    
    @TableField(fill = FieldFill.INSERT_UPDATE)
    @ApiModelProperty("更新人")
    private String updateBy;
    
    @TableLogic
    @ApiModelProperty("删除标志")
    private Integer delFlag;
}
```

## 代码贡献流程

### Git 工作流

我们采用 **Git Flow** 工作流模式：

1. **主分支**
   - `main`：生产环境分支，只接受来自 `release` 和 `hotfix` 的合并
   - `develop`：开发分支，集成所有功能开发

2. **辅助分支**
   - `feature/*`：功能开发分支
   - `release/*`：发布准备分支
   - `hotfix/*`：紧急修复分支

### 贡献步骤

1. **Fork 项目**
   ```bash
   # 在 Gitee 上 Fork 项目到你的账户
   ```

2. **克隆到本地**
   ```bash
   git clone https://gitee.com/your-username/zboot-backend-java.git
   cd zboot-backend-java
   ```

3. **添加上游仓库**
   ```bash
   git remote add upstream https://gitee.com/woshinibaba438cnmlgb/zboot-backend-java.git
   ```

4. **创建功能分支**
   ```bash
   git checkout -b feature/your-feature-name develop
   ```

5. **开发和提交**
   ```bash
   # 开发你的功能
   git add .
   git commit -m "feat: 添加用户管理功能"
   ```

6. **同步上游更新**
   ```bash
   git fetch upstream
   git rebase upstream/develop
   ```

7. **推送分支**
   ```bash
   git push origin feature/your-feature-name
   ```

8. **创建 Pull Request**
   - 在 Gitee 上创建 PR
   - 填写详细的 PR 描述
   - 等待代码审查

### Commit 规范

我们使用 [Conventional Commits](https://www.conventionalcommits.org/) 规范：

```
<type>[optional scope]: <description>

[optional body]

[optional footer(s)]
```

#### Type 类型

- `feat`: 新功能
- `fix`: 修复 bug
- `docs`: 文档更新
- `style`: 代码格式调整（不影响功能）
- `refactor`: 代码重构
- `perf`: 性能优化
- `test`: 测试相关
- `chore`: 构建过程或辅助工具的变动

#### 示例

```bash
# 新功能
git commit -m "feat(user): 添加用户头像上传功能"

# 修复 bug
git commit -m "fix(auth): 修复登录状态检查逻辑"

# 文档更新
git commit -m "docs: 更新 API 文档"

# 重构
git commit -m "refactor(service): 重构用户服务层代码"
```

### 测试示例

#### 单元测试

```java
@ExtendWith(MockitoExtension.class)
class UserServiceTest {
    
    @Mock
    private SysUserMapper userMapper;
    
    @InjectMocks
    private SysUserServiceImpl userService;
    
    @Test
    @DisplayName("根据ID获取用户信息")
    void testGetUserById() {
        // Given
        Long userId = 1L;
        UserDO userDO = new UserDO();
        userDO.setId(userId);
        userDO.setUsername("testuser");
        
        when(userMapper.selectById(userId)).thenReturn(userDO);
        
        // When
        SysUserVO result = userService.getUserById(userId);
        
        // Then
        assertThat(result).isNotNull();
        assertThat(result.getId()).isEqualTo(userId);
        assertThat(result.getUsername()).isEqualTo("testuser");
    }
}
```
