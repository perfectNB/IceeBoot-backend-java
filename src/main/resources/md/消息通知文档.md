# ZBoot 消息通知服务文档

## 概述

ZBoot消息通知服务是一个功能强大、高度可扩展的消息通知解决方案，支持邮件和短信两种主要通知方式。该服务采用响应式编程模型，基于Spring WebFlux构建，提供高并发、低延迟的消息发送能力。系统采用策略模式和工厂模式设计，支持多厂商服务集成，确保消息发送的可靠性和灵活性。

### 核心特性

- **多厂商支持**：集成主流邮件和短信服务提供商
- **响应式架构**：基于Reactor框架，支持高并发异步处理
- **统一接口**：提供一致的API接口，屏蔽底层厂商差异
- **模板引擎**：内置丰富的邮件模板，支持自定义模板
- **配置灵活**：支持多环境配置和动态切换
- **监控完善**：提供详细的发送状态和性能监控
- **安全可靠**：支持多种认证方式和加密传输

## 架构设计

### 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                    消息通知服务层                              │
├─────────────────────────────────────────────────────────────┤
│  邮件服务 (EmailService)     │    短信服务 (SMSService)      │
├─────────────────────────────────────────────────────────────┤
│              工厂层 (Factory Pattern)                       │
│  EmailFactory               │    SMSFactory                │
├─────────────────────────────────────────────────────────────┤
│                    厂商实现层                                │
│  QQ邮箱    Gmail    阿里云   │   阿里云   腾讯云   华为云     │
│  网易邮箱  Outlook  腾讯云   │   网易云   容联云   七牛云     │
├─────────────────────────────────────────────────────────────┤
│                    配置管理层                                │
│  EmailConfig               │    SMSConfig                 │
├─────────────────────────────────────────────────────────────┤
│                    数据传输层                                │
│  EmailRequest/Response     │    SMSRequest/Response       │
└─────────────────────────────────────────────────────────────┘
```

### 核心组件

#### 1. 服务接口层
- **EmailService**: 邮件服务抽象接口
- **SMSService**: 短信服务抽象接口

#### 2. 工厂管理层
- **EmailFactory**: 邮件服务工厂，负责创建和管理邮件服务实例
- **SMSFactory**: 短信服务工厂，负责创建和管理短信服务实例

#### 3. 厂商实现层
- **邮件厂商**: QQ邮箱、Gmail、网易邮箱、Outlook、阿里云、腾讯云
- **短信厂商**: 阿里云、腾讯云、华为云、网易云信、容联云、七牛云

#### 4. 配置管理层
- **EmailConfig**: 邮件服务配置管理
- **SMSConfig**: 短信服务配置管理

## 最佳实践

### 1. 服务选择策略

#### 邮件服务选择
- **企业内部通知**: 推荐使用企业邮箱（如腾讯企业邮箱、阿里云邮件推送）
- **用户注册验证**: 推荐使用专业邮件服务（如阿里云、腾讯云）
- **营销邮件**: 推荐使用专业EDM服务
- **开发测试**: 可使用个人邮箱（如QQ、Gmail）

#### 短信服务选择
- **验证码短信**: 推荐阿里云（到达率高、速度快）
- **通知短信**: 推荐腾讯云（稳定性好）
- **营销短信**: 推荐华为云（价格优势）
- **国际短信**: 推荐腾讯云（全球覆盖）

@Service
public class AsyncNotificationService {

public Mono<List<EmailResponse>> sendBatchEmailsOptimized(List<EmailRequest> requests) {
    return Flux.fromIterable(requests)
            .flatMap(request -> {
                EmailService emailService = EmailFactory.getService("default");
                return emailService.sendEmail(request)
                        .onErrorResume(error -> {
                            log.error("邮件发送失败: {}", error.getMessage());
                            return Mono.just(EmailResponse.failure(error.getMessage()));
                        });
            }, 10) // 并发度控制
            .collectList();

### 3. 错误处理

#### 重试机制
```java
public Mono<SMSResponse> sendSMSWithRetry(SMSRequest request) {
    SMSService smsService = SMSFactory.getService("aliyun");
    
    return smsService.sendSMS(request)
            .retryWhen(Retry.backoff(3, Duration.ofSeconds(1))
                    .filter(throwable -> throwable instanceof TimeoutException)
                    .onRetryExhaustedThrow((retryBackoffSpec, retrySignal) -> 
                            new RuntimeException("短信发送重试失败", retrySignal.failure())));
}
```

#### 降级处理
```java
public Mono<EmailResponse> sendEmailWithFallback(EmailRequest request) {
    return EmailFactory.getService("primary").sendEmail(request)
            .onErrorResume(error -> {
                log.warn("主要邮件服务失败，切换到备用服务: {}", error.getMessage());
                return EmailFactory.getService("secondary").sendEmail(request);
            })
            .onErrorResume(error -> {
                log.error("所有邮件服务都失败: {}", error.getMessage());
                return Mono.just(EmailResponse.failure("EMAIL_SERVICE_UNAVAILABLE", "邮件服务暂时不可用"));
            });
}
```

@Component
public class RateLimitService {
    
    private final RedisTemplate<String, String> redisTemplate;
    
    public boolean isAllowed(String phoneNumber, String type) {
        String key = "sms:rate_limit:" + type + ":" + phoneNumber;
        String count = redisTemplate.opsForValue().get(key);
        
        if (count == null) {
            redisTemplate.opsForValue().set(key, "1", Duration.ofMinutes(1));
            return true;
        }
        
        int currentCount = Integer.parseInt(count);
        if (currentCount >= 5) { // 每分钟最多5条
            return false;
        }
        
        redisTemplate.opsForValue().increment(key);
        return true;
    }
}

// 短信发送前置检查
public SMSValidationResult validateSMSRequest(SMSRequest request) {
    SMSValidationResult result = new SMSValidationResult();
    
    // 检查手机号格式
    if (!isValidPhoneNumber(request.getPhoneNumber())) {
        result.setValid(false);
        result.setErrorMessage("手机号格式不正确");
        return result;
    }
    
    // 检查签名
    if (StringUtils.isEmpty(request.getSignName())) {
        result.setValid(false);
        result.setErrorMessage("短信签名不能为空");
        return result;
    }
    
    // 检查模板ID
    if (StringUtils.isEmpty(request.getTemplateId())) {
        result.setValid(false);
        result.setErrorMessage("模板ID不能为空");
        return result;
    }
    
    // 检查频率限制
    if (!rateLimitService.isAllowed(request.getPhoneNumber(), request.getSmsType())) {
        result.setValid(false);
        result.setErrorMessage("发送频率过高，请稍后再试");
        return result;
    }
    
    result.setValid(true);
    return result;
}
