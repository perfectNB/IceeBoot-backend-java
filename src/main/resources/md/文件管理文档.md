# ZBoot 文件管理系统文档

## 1. 系统概述

ZBoot项目集成了完整的对象存储服务(OSS)解决方案，支持多种主流云存储厂商，提供统一的文件管理接口。系统采用策略模式和工厂模式设计，实现了多厂商存储服务的无缝切换和统一管理。

### 1.1 核心特性

- **多厂商支持**：集成阿里云OSS、腾讯云COS、华为云OBS、七牛云Kodo、MinIO等主流存储服务
- **统一接口**：提供标准化的文件操作接口，支持厂商间无缝切换
- **响应式编程**：基于Reactor框架，支持异步非阻塞操作
- **文件类型检查**：支持多种文件格式验证和安全检查
- **容量管理**：提供存储容量监控和管理功能
- **元数据管理**：支持文件元数据的存储和检索
- **批量操作**：支持文件的批量上传、下载和删除
- **安全控制**：提供文件访问权限控制和安全验证

## 4. 功能实现详解

### 4.1 多厂商存储集成

#### 4.1.1 阿里云OSS实现

```java
@Slf4j
public class AliyunOSSService implements OSSService {
    private static final String PROVIDER_NAME = "aliyun";
    private static final String DEFAULT_ENDPOINT = "oss-cn-hangzhou.aliyuncs.com";
    
    private OSS createOSSClient(OSSRequest request) {
        String endpoint = request.getEndpoint() != null ? request.getEndpoint() : DEFAULT_ENDPOINT;
        return new OSSClientBuilder().build(endpoint, request.getAccessKeyId(), request.getAccessKeySecret());
    }
    
    @Override
    public Mono<OSSResponse> uploadFile(OSSRequest request) {
        return Mono.fromCallable(() -> {
            OSS ossClient = createOSSClient(request);
            
            ObjectMetadata metadata = new ObjectMetadata();
            metadata.setContentLength(request.getContent().length);
            if (request.getContentType() != null) {
                metadata.setContentType(request.getContentType());
            }
            
            ByteArrayInputStream inputStream = new ByteArrayInputStream(request.getContent());
            PutObjectResult result = ossClient.putObject(
                request.getBucketName(), 
                request.getObjectKey(), 
                inputStream, 
                metadata
            );
            
            return OSSResponse.success()
                    .setProvider(getProvider())
                    .setFileUrl(buildFileUrl(request))
                    .setEtag(result.getETag());
        });
    }
}
```

#### 4.1.2 腾讯云COS实现

```java
@Slf4j
public class TencentCOSService implements OSSService {
    private static final String PROVIDER_NAME = "tencent";
    private static final String DEFAULT_REGION = "ap-beijing";
    
    private COSClient createCOSClient(OSSRequest request) {
        COSCredentials cred = new BasicCOSCredentials(
            request.getAccessKeyId(), 
            request.getAccessKeySecret()
        );
        String regionName = request.getRegion() != null ? request.getRegion() : DEFAULT_REGION;
        Region region = new Region(regionName);
        ClientConfig clientConfig = new ClientConfig(region);
        return new COSClient(cred, clientConfig);
    }
    
    @Override
    public Mono<OSSResponse> uploadFile(OSSRequest request) {
        return Mono.fromCallable(() -> {
            COSClient cosClient = createCOSClient(request);
            
            ObjectMetadata metadata = new ObjectMetadata();
            metadata.setContentLength(request.getContent().length);
            if (request.getContentType() != null) {
                metadata.setContentType(request.getContentType());
            }
            
            ByteArrayInputStream inputStream = new ByteArrayInputStream(request.getContent());
            PutObjectRequest putRequest = new PutObjectRequest(
                request.getBucketName(), 
                request.getObjectKey(), 
                inputStream, 
                metadata
            );
            PutObjectResult result = cosClient.putObject(putRequest);
            
            return OSSResponse.success()
                    .setProvider(getProvider())
                    .setFileUrl(buildFileUrl(request));
        });
    }
}
```

#### 4.1.3 MinIO实现

```java
@Slf4j
public class MinIOService implements OSSService {
    private static final String PROVIDER_NAME = "minio";
    private static final String DEFAULT_ENDPOINT = "http://localhost:9000";
    
    private MinioClient createMinioClient(OSSRequest request) {
        String endpoint = request.getEndpoint() != null ? request.getEndpoint() : DEFAULT_ENDPOINT;
        
        MinioClient.Builder builder = MinioClient.builder()
                .endpoint(endpoint)
                .credentials(request.getAccessKeyId(), request.getAccessKeySecret());
        
        if (request.getRegion() != null) {
            builder.region(request.getRegion());
        }
        
        return builder.build();
    }
    
    @Override
    public Mono<OSSResponse> uploadFile(OSSRequest request) {
        return Mono.fromCallable(() -> {
            MinioClient minioClient = createMinioClient(request);
            
            ByteArrayInputStream inputStream = new ByteArrayInputStream(request.getContent());
            
            PutObjectArgs.Builder putObjectBuilder = PutObjectArgs.builder()
                    .bucket(request.getBucketName())
                    .object(request.getObjectKey())
                    .stream(inputStream, request.getContent().length, -1);
            
            if (request.getContentType() != null) {
                putObjectBuilder.contentType(request.getContentType());
            }
            
            ObjectWriteResponse response = minioClient.putObject(putObjectBuilder.build());
            
            return OSSResponse.success()
                    .setProvider(getProvider())
                    .setFileUrl(buildFileUrl(request))
                    .setEtag(response.etag());
        });
    }
}
```

### 4.3 工具类功能

#### 4.3.1 文件名处理

```java
public class OSSUtils {
    // 生成唯一的对象键
    public static String generateUniqueObjectKey(String originalFileName) {
        String extension = getFileExtension(originalFileName);
        String timestamp = LocalDateTime.now().format(DateTimeFormatter.ofPattern("yyyyMMdd/HHmmss"));
        String uuid = UUID.randomUUID().toString().replace("-", "");
        
        if (extension != null && !extension.isEmpty()) {
            return String.format("%s/%s.%s", timestamp, uuid, extension);
        } else {
            return String.format("%s/%s", timestamp, uuid);
        }
    }
    
    // 生成基于日期的对象键
    public static String generateDateBasedObjectKey(String originalFileName, String prefix) {
        String extension = getFileExtension(originalFileName);
        String date = LocalDateTime.now().format(DateTimeFormatter.ofPattern("yyyy/MM/dd"));
        String fileName = getFileNameWithoutExtension(originalFileName);
        String timestamp = String.valueOf(System.currentTimeMillis());
        
        StringBuilder keyBuilder = new StringBuilder();
        if (prefix != null && !prefix.trim().isEmpty()) {
            keyBuilder.append(prefix.trim()).append("/");
        }
        keyBuilder.append(date).append("/");
        keyBuilder.append(fileName).append("_").append(timestamp);
        
        if (extension != null && !extension.isEmpty()) {
            keyBuilder.append(".").append(extension);
        }
        
        return keyBuilder.toString();
    }
}
```

```java
public static boolean isFileTypeAllowed(String fileName, List<String> allowedTypes) {

    if (extension == null) {
```

#### 4.3.3 请求验证

```java
// 基础请求验证
public static void validateRequest(OSSRequest request) throws OSSException {
    if (request == null) {
        throw new OSSException("INVALID_REQUEST", "请求参数不能为空");
    }
    
    if (request.getBucketName() == null || request.getBucketName().trim().isEmpty()) {
        throw new OSSException("INVALID_BUCKET_NAME", "存储桶名称不能为空");
    }
    
    if (request.getObjectKey() == null || request.getObjectKey().trim().isEmpty()) {
        throw new OSSException("INVALID_OBJECT_KEY", "对象键不能为空");
    }
    
    if (request.getAccessKeyId() == null || request.getAccessKeyId().trim().isEmpty()) {
        throw new OSSException("INVALID_ACCESS_KEY", "访问密钥ID不能为空");
    }
    
    if (request.getAccessKeySecret() == null || request.getAccessKeySecret().trim().isEmpty()) {
        throw new OSSException("INVALID_SECRET_KEY", "访问密钥Secret不能为空");
    }
}

// 上传请求验证
public static void validateUploadRequest(OSSRequest request) throws OSSException {
    validateRequest(request);
    
    if (request.getContent() == null && request.getInputStream() == null) {
        throw new OSSException("INVALID_CONTENT", "文件内容不能为空");
    }
    
    if (request.getContentLength() != null && request.getContentLength() <= 0) {
        throw new OSSException("INVALID_CONTENT_LENGTH", "文件大小必须大于0");
    }
}
```

```java
@RestController
@RequestMapping("/v1/files")
public class FileController {
    
    @Autowired
    private OSSFactory ossFactory;
    
    @Autowired
    private OSSConfig ossConfig;
    
    @PostMapping("/upload")
    public Mono<ResponseEntity<OSSResponse>> uploadFile(
            @RequestParam("file") MultipartFile file,
            @RequestParam(value = "provider", required = false) String provider,
            @RequestParam(value = "bucketName", required = false) String bucketName) {
        
        return Mono.fromCallable(() -> {
            // 参数处理
            String actualProvider = provider != null ? provider : ossConfig.getDefaultProvider();
            String actualBucketName = bucketName != null ? bucketName : getDefaultBucketName(actualProvider);
            
            // 文件验证
            if (file.isEmpty()) {
                throw new IllegalArgumentException("文件不能为空");
            }
            
            if (!OSSUtils.isFileTypeAllowed(file.getOriginalFilename(), 
                    Arrays.asList(ossConfig.getGlobal().getAllowedFileTypes()))) {
                throw new IllegalArgumentException("不支持的文件类型");
            }
            
            if (!OSSUtils.isFileSizeAllowed(file.getSize(), ossConfig.getGlobal().getMaxFileSize())) {
                throw new IllegalArgumentException("文件大小超出限制");
            }
            
            // 创建请求
            OSSRequest request = new OSSRequest()
                    .setBucketName(actualBucketName)
                    .setObjectKey(OSSUtils.generateUniqueObjectKey(file.getOriginalFilename()))
                    .setContent(file.getBytes())
                    .setContentType(file.getContentType())
                    .setOriginalFileName(file.getOriginalFilename())
                    .setAccessKeyId(getAccessKeyId(actualProvider))
                    .setAccessKeySecret(getAccessKeySecret(actualProvider));
            
            return request;
        })
        .flatMap(request -> {
            OSSService ossService = ossFactory.getService(provider != null ? provider : ossConfig.getDefaultProvider());
            return ossService.uploadFile(request);
        })
        .map(response -> ResponseEntity.ok(response))
        .onErrorReturn(ResponseEntity.badRequest().build());
    }
    
    @GetMapping("/download")
    public Mono<ResponseEntity<byte[]>> downloadFile(
            @RequestParam("provider") String provider,
            @RequestParam("bucketName") String bucketName,
            @RequestParam("objectKey") String objectKey) {
        
        OSSService ossService = ossFactory.getService(provider);
        
        OSSRequest request = new OSSRequest()
                .setBucketName(bucketName)
                .setObjectKey(objectKey)
                .setAccessKeyId(getAccessKeyId(provider))
                .setAccessKeySecret(getAccessKeySecret(provider));
        
        return ossService.downloadFile(request)
                .map(response -> {
                    if (response.getSuccess()) {
                        HttpHeaders headers = new HttpHeaders();
                        headers.setContentType(MediaType.parseMediaType(response.getContentType()));
                        headers.setContentLength(response.getContent().length);
                        headers.setContentDispositionFormData("attachment", 
                                response.getExtraData() != null ? 
                                        (String) response.getExtraData().get("originalFileName") : 
                                        objectKey);
                        
                        return ResponseEntity.ok()
                                .headers(headers)
                                .body(response.getContent());
                    } else {
                        return ResponseEntity.notFound().build();
                    }
                })
                .onErrorReturn(ResponseEntity.internalServerError().build());
    }
}
```

```java
@Service
public class AsyncFileService {
    
    @Autowired
    private OSSFactory ossFactory;
    
    @Async
    public CompletableFuture<List<String>> batchUpload(List<FileUploadRequest> requests) {
        List<Mono<String>> uploadTasks = requests.stream()
                .map(this::uploadSingleFile)
                .collect(Collectors.toList());
        
        return Flux.merge(uploadTasks)
                .collectList()
                .toFuture();
    }
    
    private Mono<String> uploadSingleFile(FileUploadRequest request) {
        OSSService ossService = ossFactory.getService(request.getProvider());
        
        OSSRequest ossRequest = new OSSRequest()
                .setBucketName(request.getBucketName())
                .setObjectKey(OSSUtils.generateUniqueObjectKey(request.getFileName()))
                .setContent(request.getContent())
                .setContentType(OSSUtils.getContentType(request.getFileName()))
                .setAccessKeyId(request.getAccessKeyId())
                .setAccessKeySecret(request.getAccessKeySecret());
        
        return ossService.uploadFile(ossRequest)
                .map(OSSResponse::getFileUrl)
                .doOnSuccess(url -> log.info("文件上传成功: {}", url))
                .doOnError(error -> log.error("文件上传失败: {}", error.getMessage()));
    }
}
```

```java
@Service
public class MultipartUploadService {
    
    private static final long MULTIPART_THRESHOLD = 100 * 1024 * 1024L; // 100MB
    private static final long PART_SIZE = 10 * 1024 * 1024L; // 10MB
    
    public Mono<String> uploadLargeFile(String provider, String bucketName, String objectKey, 
                                        InputStream inputStream, long contentLength) {
        if (contentLength <= MULTIPART_THRESHOLD) {
            // 普通上传
            return uploadNormalFile(provider, bucketName, objectKey, inputStream, contentLength);
        } else {
            // 分片上传
            return uploadMultipartFile(provider, bucketName, objectKey, inputStream, contentLength);
        }
    }
    
    private Mono<String> uploadMultipartFile(String provider, String bucketName, String objectKey, 
                                            InputStream inputStream, long contentLength) {
        // 实现分片上传逻辑
        long partCount = (contentLength + PART_SIZE - 1) / PART_SIZE;
        
        return Flux.range(1, (int) partCount)
                .flatMap(partNumber -> uploadPart(provider, bucketName, objectKey, inputStream, partNumber))
                .collectList()
                .flatMap(parts -> completeMultipartUpload(provider, bucketName, objectKey, parts));
    }
}
```

```java
@Aspect
@Component
public class OSSOperationLogger {
    
    private static final Logger log = LoggerFactory.getLogger(OSSOperationLogger.class);
    
    @Around("execution(* com.iceeboot.common.service.oss.service.OSSService.uploadFile(..))")
    public Object logUploadOperation(ProceedingJoinPoint joinPoint) throws Throwable {
        long startTime = System.currentTimeMillis();
        OSSRequest request = (OSSRequest) joinPoint.getArgs()[0];
        
        try {
            Object result = joinPoint.proceed();
            long duration = System.currentTimeMillis() - startTime;
            
            log.info("文件上传成功 - Provider: {}, Bucket: {}, ObjectKey: {}, Size: {}, Duration: {}ms",
                    getProviderFromJoinPoint(joinPoint),
                    request.getBucketName(),
                    request.getObjectKey(),
                    request.getContent() != null ? request.getContent().length : 0,
                    duration);
            
            return result;
        } catch (Exception e) {
            long duration = System.currentTimeMillis() - startTime;
            
            log.error("文件上传失败 - Provider: {}, Bucket: {}, ObjectKey: {}, Error: {}, Duration: {}ms",
                    getProviderFromJoinPoint(joinPoint),
                    request.getBucketName(),
                    request.getObjectKey(),
                    e.getMessage(),
                    duration);
            
            throw e;
        }
    }
    
    private String getProviderFromJoinPoint(ProceedingJoinPoint joinPoint) {
        Object target = joinPoint.getTarget();
        if (target instanceof OSSService) {
            return ((OSSService) target).getProvider();
        }
        return "unknown";
    }
}
```

## 11. 故障排查

### 11.1 常见问题

#### 11.1.1 上传失败

**现象**：文件上传返回错误

**排查步骤**：
1. 检查访问密钥是否正确
2. 验证存储桶是否存在
3. 检查文件大小是否超限
4. 验证文件类型是否允许
5. 检查网络连接状态

#### 11.1.2 下载缓慢

**现象**：文件下载速度很慢

**排查步骤**：
1. 检查网络带宽
2. 验证CDN配置
3. 检查存储区域设置
4. 优化连接池配置

**排查步骤**：
